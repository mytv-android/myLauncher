  • 排列：天气在最左，用分隔线与"日期 + 时钟"隔开。日期和时钟是一组，底板右缘固定，所以天气出现或消失时，日期和时钟都不移动；没有天气数据时，天气单元和分隔线一起收起，不留孤立的分隔线。
  • 出现范围：顶栏可见时都显示，即主页的 Hero 与浏览态、应用页、小组件页。手机与电脑页、查看页、播放页本来就隐藏顶栏；环境模式顶栏淡出，天气、日期与农历改由 A5 的布局显示。
  • 焦点：状态底板不可聚焦。焦点在齿轮上按 → 仍是边界，播放 FX_KEYPRESS_INVALID。顶栏的焦点链、BACK 链和 HOME 行为都不变。
  • 触屏与鼠标：点按、长按都不响应。
  • 读屏：天气单元的 contentDescription 为状况名加温度，例如"晴 14°"，这串文字已在界面文字白名单的模式里；日期和时钟按原文字朗读。
  • 不显示：城市名、状况文字、最高 / 最低温（理由见 A6）。

对比度守护

顶栏右端不在 §06 的遮罩范围里：横向遮罩到 72% 画面宽度就透明了，底部遮罩只盖下半部。海报右上角是亮天空时，Chrome 玻璃 50% 的底色压不住，白字会糊。规则如下，胶囊组用同一个结果，顶栏两块始终一致。

  1. 背景层换图后（§08，焦点停留 260ms），在已解码的背景图上取状态底板覆盖的矩形，分成 12×3 格，取相对亮度最高一格的平均色。
  2. 依次试不透明度 50%、65%、80%：把 surfaceContainer 按这个不透明度叠在上一步的颜色上，得到底板色；底板里最弱的文字（日期，onSurfaceVariant）对它的对比度达到 4.5:1 就用这一档。三档都不够时用 80%。
  3. 换档用 effects default 过渡。T3 纯色底板已是 94%，不计算。环境模式不用底板。
// :core:glass —— 状态底板与胶囊组的不透明度档位
private val PLATE_ALPHAS = floatArrayOf(0.50f, 0.65f, 0.80f)

// 按 sRGB 逐通道叠加，与合成器一致；不要用 Compose 的 lerp(Color, Color, Float)，它在 Oklab 中插值
private fun over(top: Color, alpha: Float, bottom: Color) = Color(
  red = top.red * alpha + bottom.red * (1 - alpha),
  green = top.green * alpha + bottom.green * (1 - alpha),
  blue = top.blue * alpha + bottom.blue * (1 - alpha),
)

// brightest：底板下方最亮一格的平均色；tint：surfaceContainer；text：onSurfaceVariant
fun plateAlpha(brightest: Color, tint: Color, text: Color): Float =
  PLATE_ALPHAS.firstOrNull { a ->
    ColorUtils.calculateContrast(text.toArgb(), over(tint, a, brightest).toArgb()) >= 4.5
  } ?: PLATE_ALPHAS.last()

原型里"明亮海报"的右上角是太阳附近的天空，守护会取 80%；控制栏下方显示实时计算结果。原型用浏览器的 backdrop-filter 模拟 T1，饱和度增强会让实际观感比计算值略亮。

天气图标

一眼要看的是"冷不冷、下不下雨"，所以图标靠造型区分，颜色只做加强。七种造型，晴和多云各有夜间变体。

  • 昼夜：§12 的 current 请求增加 is_day；为 0 时晴、多云用月亮。其他状况不分昼夜。
  • 造型：24dp 网格，填充造型（十英尺下比描边好认）。云用 onSurfaceVariant；太阳、月亮、雨滴、雪粒、闪电用状况色。雾只用横线，不带云，和雨从轮廓上就能分开。
  • 状况色：设计色经 MCU Blend.harmonize 向当前主色偏移（最多 15°），再取 HCT 色调 80；高对比焦点框开启或长辈模式时取 90。设计色：太阳 #F5B43C、月亮 #C9D3F2、雨 #5EA2F0、雪 #E3ECFA、闪电 #F7D046。原型使用未经调和的固定色。
  • 资源：9 个 VectorDrawable 放在 core:designsystem，不引入图标库。
  • 文字：16 个状况名与"14°"格式都已在 acceptance/spec/ui_copy.json 中，不新增界面文字。负温用 ASCII 连字符"-3°"，与白名单模式 ^-?\d{1,2}°$ 一致。

A6

取舍

以下做法考虑过，没有采用。实现方按本补充实现，不要自行加回。

不可聚焦

顶栏的焦点链保持不变。没有专门的天气页可去，一个聚焦后按 OK 什么也不发生的元素只会让人困惑。最高 / 最低温和更多信息留在"时钟与天气"小组件。

天气只放图标和温度

状况名作为 contentDescription 留给读屏。底板里已经有日期，再放状况文字会和 Tab 抢视线。

日期不放在时钟下方

v3.4 字号表写的是"时钟下方一行"。顶栏只有一行高（y 22–66），两行会让底板比胶囊组高，也会贴近 Hero。改为放在底板里、时钟左侧，与时钟基线对齐，字号仍是 13sp。

不加显示开关

没有数据时底板本来就不占位。若需要"在顶栏显示天气"开关，要在桌面设置加一项，并把这条文字加进界面文字白名单。

只用摄氏度

界面只有简体中文，温度不带单位字母。
