# ADR-004：顶栏的天气与时钟并入工具胶囊

- 状态：接受（2026-11-06，用户在第二版顶栏方案中选择方案 A「合一胶囊」）
- 日期：2026-11-06
- 影响：补充 A 的 A2「顶栏状态底板」；快速设置标题行；D327（`clock` 标签）、D210（模糊区域数）。不改动验收工具包

## 背景

补充 A 的 A2 在顶栏右端放一块独立的状态底板：天气、分隔线、日期与农历、时钟，与工具胶囊并排，同为 Chrome 玻璃。实现后，用户认为顶栏右侧"都加框"、不好看。用户先否掉了第一版的四个方案（浮字、角落大时钟、天气进胶囊、天气光晕），又在第二版的四个方案里选了 A。第二版的另外三个方案是：天气色片、Expressive 形状、整条顶栏不要框。最后一个需要改 D207–D209。

方案稿：`docs/adr/assets/ADR-004-topbar-v2.html`（深色 / 明亮海报、五种天气可切换）。

## 方案

- 工具胶囊向右延长，依次是：搜索、环境模式、快速设置，1×18dp 的分隔线（onSurface 24%），天气图标（22dp，A3 造型）加温度（17sp），时钟（18sp）。数字用等宽字形。
- 分隔线之后的部分不可聚焦，点按与长按都不响应。焦点在齿轮上按 → 仍是边界，播放 FX_KEYPRESS_INVALID。
- 没有天气数据时，天气单元收起，分隔线保留，把时钟与按钮隔开。
- 时钟保留测试标签 `clock`，12 / 24 小时制按 §12 不变（D327）。
- 日期与农历（"11月6日 周五 · 九月廿八"）移到快速设置的标题下，11.5sp，onSurfaceVariant。环境模式、屏保、时钟小组件里的日期与天气不变。
- A2 的对比度守护（50% / 65% / 80% 三档）照旧作用在这块胶囊上，取样区仍是画面右上角。
- 顶栏只剩两块玻璃（Tab 组、工具胶囊），`blurRegionCount` 原本就按 2 块计。快速设置打开时共 3 块，仍满足 §07 的上限。
- 快速设置标题行由 30dp 增到 38dp，区块间距由 9dp 减到 8dp。出现第四排磁贴（儿童 / 长辈模式，或有勿扰）时，面板仍不滚动。

## 不采用

- A2 原样的独立状态底板：用户否决。
- 方案 D（整条顶栏不要框）：要改 D207–D209 的测法并重新冻结工具包。

## 影响

- 顶栏右侧宽度：有天气约 270dp，无天气约 200dp，比 A2 的状态底板加胶囊少约 160dp。
- 界面文字不增加。温度"19°"、时钟、日期行原本就在 `ui_copy.json` 的模式里。
- 长辈模式的放大尺寸（A2 长辈模式一列）暂按默认尺寸，M5 前再定。
