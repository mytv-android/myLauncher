# ADR-002：按 IP 推测城市的数据源

- 状态：接受（2026-11-03，用户选择方案 B：换免费服务商）
- 日期：2026-11-03
- 影响：M3 天气、T04 天气策略测试、S09 权限

## 背景

设计稿 §12 写的是：没有设置城市时用 ipinfo.io 推测，最多每天一次；不申请定位权限。M0 核对了 ipinfo.io 的公开条款与接口（证据：`docs/m0/evidence/item11-ipinfo.md`）：

- API 现在要求 token（`https://ipinfo.io/developers`）。
- 免费 Lite 只返回国家级数据（`https://ipinfo.io/pricing`，`Country-level only`）；城市级需要付费 Core（$26/月）。
- 无 token 的 `https://ipinfo.io/json` 实测返回 HTTP 429 `Sign up at ipinfo.io`。
- Terms of Service（2024-06-03）允许内部业务使用、禁止转售；Acceptable Use Policy 禁止未授权的自动化访问。
- 条款没有缓存/保留期限；隐私政策将 IP 作为设备信息收集，用于生成 generalized location。

因此“无密钥、免费、城市级、每天一次”的四个条件无法同时满足。

## 选项

### A. 申请 ipinfo.io token + Core 付费计划

- 满足城市级与条款；需要密钥分发（不能让 token 进公开 APK）、月费与配额管理。
- 与“无密钥”的设计前提冲突，需要用户承担费用与密钥管理。

### B. 换一个允许免费城市级查询的服务

- 需要重新核对条款、配额、隐私与稳定性；常见免费服务通常限非商业、要求署名或有速率限制。
- 需要在 M3 前选定并写 ADR。

### C. 取消 IP 推测

- 未设置城市时显示“当前城市：未设置”，由用户在「手机与电脑」网页设置城市。
- 最简单、无第三方依赖、无隐私争议；代价是首次使用时天气不可用，直到用户设置城市。
- 需要把设计稿中的“按网络位置”文案与 T04 的 IP 推测断言移除/调整；影响 `acceptance/spec/required_tests.json` 的 T04，属于要用户决定的工具包变更。

### D. 仅用国家级数据选默认城市

- 用 ipinfo Lite 或系统区域选一个默认城市（例如国家首都），允许用户覆盖。
- 免费且无 token 不可行（Lite 仍需 token），但可以用系统 locale/国家而不是 IP；不需要第三方服务。
- 天气可能不准确，但不涉及 IP 与定位。

## 决定

采用方案 B，具体服务商为 **ipwho.is**。M0 实测与文档核对结果：

- 接口：`https://ipwho.is/`（HTTPS，无 token）。返回 `city`、`region`、`latitude`、`longitude`、`country` 等城市级字段。
- 免费额度：1,000 请求/天/客户端 IP；超过返回 HTTP 429，24 小时后恢复。每天最多一次远低于上限。
- 条款：免费计划允许商业使用；限制为“personal or internal business purposes”，禁止转售/再分发；低量自动化查询不在禁止之列；没有署名要求；没有缓存/保留期限条款。
- 隐私：隐私政策把网站访问者 IP 作为使用数据记录；对“客户端应用提交的 API 查询 IP”没有明确说明保留期限。残余风险：每天最多一次、不带设备标识、HTTPS、不申请定位权限；不向用户展示原始 IP。
- 不选 ip-api.com：免费仅限非商业，免费无 HTTPS（明文），不适合电视应用；不选 ipapi.co：免费为试用、不可用于生产，实测被 Cloudflare 403。

实现要求（M3）：

- 只在未设置城市时请求，每天最多一次；结果缓存到当天结束，失败不循环重试。
- 只请求 `https://ipwho.is/`，不把 IP 或设备标识放进 URL 之外的字段；不使用 `lang=native` 等 Pro 参数。
- 天气请求仍只带两位小数的经纬度与语言；不申请任何定位权限（S09 不变）。
- T04 的断言（每小时最多一次、缓存 3 小时、失败退避、IP 推测每天最多一次、设置城市后不再推测、只带两位小数经纬度）不变；单元测试用固定响应，不访问网络。
- 城市显示名优先用内置城市表按经纬度就近匹配中文名；匹配不到时显示 ipwho.is 返回的 `city` 原文（属于内容数据，不是界面提示文字）。

## 影响的检查

- T04 `WeatherPolicyTest`：IP 推测每天最多一次、设置城市后不再推测
- M3 天气与顶栏/时钟小组件的城市文案
- S09：仍不得申请定位权限（所有选项都满足）
