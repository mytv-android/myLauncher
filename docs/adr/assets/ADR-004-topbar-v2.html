顶栏右侧 · 第二版

第一版的四个方案都是"框 + 小字"或"小字浮在海报上"的变体。这一版换了四个思路：把状态并进已有的胶囊、只给天气一块有颜色的色片、用 M3 Expressive 的形状承载天气、整条顶栏都不要框。每个方案都可以切换背景和天气，最难的是"明亮海报"。画面按 960×540 dp 绘制，和电视上的实际比例一致。

方案 C · Expressive 形状

最有品牌感
右上角放大 · 深色海报
右上角放大 · 明亮海报

天气装进一个 M3 Expressive 形状：晴天是 Sunny，多云是 Cookie，雨天是 Clover，夜间是 Circle；形状按天气上色（晴琥珀、多云灰蓝、雨浅蓝、夜间淡紫，色调 T90），图标是 T10 的单色线稿。天气变化时形状用 MaterialShapes 的 Morph 过渡，和应用图标聚焦时变 Cookie 是同一套语言。温度和时钟同字号并排，中间一个圆点。
