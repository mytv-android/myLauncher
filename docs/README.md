# docs/

本目录同时作为 GitHub Pages 的发布源（仓库 Settings → Pages → Source: `main` / `docs`）。

- 站点地址：<https://mytv-android.github.io/myLauncher/>
- `index.html` 是仓库根目录 `tv-launcher-design-v3.html` 的**发布副本**，内容以根目录版本为准
- 设计稿更新后，重新生成本文件即可：
  ```
  cp tv-launcher-design-v3.html docs/index.html
  ```
- 后续里程碑说明（`docs/milestones/Mx.md`）、ADR（`docs/adr/`）、验收问题记录（`docs/acceptance-issues.md`）也会一并发布到站点下
