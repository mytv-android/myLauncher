## 已知问题与限制

- **应用排序改为最近更新时间**：`你的应用` 行按 `PackageInfo.lastUpdateTime` 从新到旧排序（设计稿未规定顺序），重装/更新后的应用会回到行首；最多 10 个位置。
- **应用页导航按坐标**：应用页的磁贴焦点顺序不一定与网格行序一致，检查按无障碍树里的磁贴坐标移动焦点（`seek_grid_bounds`），不再依赖蛇形扫描。
- **模拟器帧率**：软件/宿主渲染下 P95 与卡顿帧不代表真机表现，玻璃降档与帧预算行为只在真机有意义。
- **M2 矩阵中的 api23 / api36 未在本次正式验收中执行**：按用户指示 M2–M4 一次性验收，正式报告使用 M4 的设备矩阵。
- M1 遗留的「移动菜单项占位」等已知问题仍然存在，见 `docs/milestones/M1.md`。

## 设计稿未写明、按实现需要补充的细节

- **取色节流**：连续移动时最多 2 次主题过渡，之后要等焦点稳定 180 ms 才允许下一次。
- **低彩度判定**：种子色的 chroma 低于阈值时不改主题，保持当前全局主题；`files` 的灰色图标即此情况。
- **SeedCache**：种子按 `包名/类名` 与图标内容哈希缓存，算法版本号 `SEED_ALGORITHM_VERSION = 1`；缓存失效自动重算。
- **对比度级别与风格**：三个对比度级别映射到 MCU 的 ContrastLevel（-1 / 0 / 1），四种风格映射到 `SchemeStyle`（tonal / vibrant / expressive / neutral）。
- **背景层**：焦点停留 260 ms 后切换背景，交叉淡入；环境来源与焦点内容关联。
- **玻璃档位**：API 31+ 自动选 T1，API 23–30 选 T2，手动档位可覆盖；运行中帧预算超限自动降档并提示一次。
- **高对比焦点框**：4 dp 白框 + 2 dp 黑描边；长辈模式强制开启，桌面设置可开关。
